# Contributing

**This project does not accept code contributions.**

That is not a judgement about anyone's code. It is a licensing consequence: the
repository is proprietary rather than open source (see [LICENSE](LICENSE)), and
merging outside code into a proprietary codebase creates ownership questions
this project has no interest in carrying. Pull requests from people other than
the repository owner will be closed without review.

The repository is public so the work can be read and assessed — a portfolio,
not a collaboration.

## What is welcome

**Data corrections, as issues.** This is a Formula 1 data project, and accuracy
matters more here than anything else in it. If a figure is wrong, please open
an issue with:

- what the application shows, and where (page or endpoint)
- what the correct value is
- a source — the FIA classification, a race report, or the upstream provider

Corrections of this kind are genuinely useful and will be acted on.

**Bug reports, as issues.** Something crashes, renders blank, or contradicts
itself. Please include the route and what you expected.

**Questions about method.** How a metric is defined, why a denominator is what
it is, why a season is treated the way it is. [METHODOLOGY.md](METHODOLOGY.md)
should answer most of these; if it does not, that is a documentation gap worth
reporting.

## What is not welcome

- Pull requests (see above)
- Feature requests. Scope is deliberately fixed.
- Automated scanner output with no demonstrated impact
- Security vulnerabilities in public issues — use [SECURITY.md](SECURITY.md)

## Reusing this code

You need written permission. Open an issue to ask. Reading it, learning from
it, and referring to it are all fine without asking.
